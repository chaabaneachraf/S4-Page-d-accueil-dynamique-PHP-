## Synthèse de ma veille technologique
- **Définition en une phrase :** La modularité en PHP, c’est couper le code en petits fichiers et en petites fonctions pour les réutiliser.
- **Problème résolu pour le projet :** : Le menu et le footer sont copiés dans plusieurs pages. Avec la modularité, j’écris le code une seule fois, je le réutilise partout, et je change un seul fichier quand je modifie quelque chose.
- **Mes 3 mots-clés :** require_once — Fonctions réutilisables — Principe DRY
